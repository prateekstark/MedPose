## Implementation implications (recommendations, not source claims)

Keep cohort-pooled and within-trial offset correction separate. Report raw error, corrected error and usable coverage together. Treat clinical markerless references separately from marker-based validation. Do not select a model based on an unverified VRAM requirement or equate an accessible model card with unrestricted runtime assets. Do not implement a dataset-specific loader from guessed paths.

Task 1 has an evidence row for every requested topic, but remains incomplete wherever marked NOT FOUND. Exact original GDI implementation assets, mesh redistribution rights, several dataset metadata fields and most inference-memory minima need follow-up.
